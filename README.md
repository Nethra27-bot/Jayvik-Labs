# 🌐 Computer Networking Basics

## 📌 Overview

This repository contains my beginner-friendly notes on fundamental computer networking concepts that are essential for learning **Cybersecurity, Ethical Hacking, and Penetration Testing**.

The goal is to understand how devices communicate, how networks operate, and how networking knowledge helps identify and prevent security threats.

## 🎯 Topics Covered

1. **Computer Network** – Introduction to network communication and resource sharing.
2. **Client vs Server** – Understanding request-and-response communication.
3. **LAN (Local Area Network)** – Networking within a limited geographical area.
4. **WAN (Wide Area Network)** – Connecting networks across large geographical areas.
5. **Network Switch** – Connecting devices within a local network.
6. **Router** – Forwarding data packets between networks.
7. **Firewall** – Filtering network traffic based on security rules.
8. **IP Address** – Understanding IPv4 and IPv6 addressing.
9. **MAC Address** – Learning link-layer addressing.
10. **Default Gateway** – Understanding communication with external networks.
11. **DNS (Domain Name System)** – Resolving domain names to IP addresses.
12. **Networking in Cybersecurity** – Applying networking concepts to security analysis.

## 🔐 Importance in Cybersecurity

Networking fundamentals are essential for understanding:

* Network scanning using Nmap
* Packet analysis using Wireshark
* Open ports and network services
* Firewall rules and traffic filtering
* Network reconnaissance and vulnerability assessment
* Network attack detection and prevention
* Penetration testing in authorized lab environments

## 🛠️ Tools to Explore

* **Nmap** – Network discovery and port scanning
* **Wireshark** – Network packet analysis
* **Kali Linux** – Security testing environment
* **VMware Workstation Pro** – Virtual lab setup

## 📚 Learning Outcome

Through these notes, I am building a strong foundation in IP addressing, network devices, network communication, and security fundamentals as part of my cybersecurity learning journey.
